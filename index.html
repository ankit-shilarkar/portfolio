Notes to self

Short things I learned, newest first. The assistant reads these too.

  1. 09 Oct 2026

    Kafka only orders messages within a partition

    Ordering is per partition, not per topic. If events for one order must stay in sequence, give them the same key so they land in the same partition.

    Kafka · ordering

  2. 09 Oct 2026

    Cache-aside puts the cache on the read path only

    Read from Redis; on a miss, read the database and fill the cache. On writes, update the database and delete the key rather than updating it, which avoids racing writers leaving stale data.

    Redis · caching

  3. 09 Oct 2026

    Timer-triggered Azure Functions use six-field cron

    The NCRONTAB format starts with seconds: 0 */5 * * * * runs every five minutes, not every five seconds.

    Azure Functions · cron
