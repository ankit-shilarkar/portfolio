DocMind: AI document processing

Demo
  1. Upload PDF / image
  2. Tika + OCR
  3. Claude: classify & extract
  4. PostgreSQL
  5. REST API
Problem
Invoices, contracts and reports need manual extraction and classification.
Approach
An async Kafka pipeline extracts text, has an LLM pull structured fields, and stores them behind a queryable, JWT-secured API with per-tenant isolation.
Outcome
Designed for ~80% less manual processing and 500+ documents an hour. Redis catches duplicate documents and LLM calls are rate-limited to control cost.

Spring Boot · Claude API · Apache Tika · Kafka · PostgreSQL · Redis · Docker
